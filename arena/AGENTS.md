# AGENTS.md — yolo-arena

## 1. Role
Pilier d'evaluation comparative et de benchmarking universel 2026 pour :
- LLM inference & latency (Gemma 4, Llama 3.3, Claude, GPT-4o, DeepSeek).
- Agent execution accuracy & context adherence.
- RAG precision, recall et vitesse de recuperation vectorielle SIMD.

## 2. Commandes Canoniques
- `bun test tests` : Tests unitaires de la suite de benchmark.
- `bun run src/cli.ts` : Lancement du leaderboard comparatif en CLI/TUI.
