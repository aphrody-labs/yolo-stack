# yolo-arena — Universal 2026 AI Benchmark Leaderboard

Plateforme souveraine d'evaluation et de classement comparatif pour modeles LLM, pipelines RAG et agents autonomes.

## Capacites
- Mesure de debit de tokens et latence premier token (TTFT).
- Evaluation de la fidelite contextuelle et du respect des contraintes d'agents.
- Benchmarks de performance RAG acceleres par SIMD.

## Commandes
```bash
# Tests unitaires
bun test tests

# Execution du leaderboard en console
bun run src/cli.ts
```
