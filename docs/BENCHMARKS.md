# Benchmarks: TanStack on Bun vs Leptos vs Dioxus 0.8

Date compiled: 2026-11-04. Every number below is tagged `measured` (run here, receipt in
`docs/receipts/`), `quoted` (public source, URL and retrieval date given) or `missing` (no public
number found; nothing invented). Versions on 2026-11-04: `@tanstack/react-start` 1.169.4,
`@tanstack/react-router` 1.170.46 (release 2026-10-22); `leptos` 0.8.23 stable (2026-10-31), 0.9.0-rc1
(2026-10-31), `cargo-leptos` 0.3.11 (2026-10-02); `dioxus` 0.7.10 stable (2026-07-30), 0.8.0-alpha.3
(2026-10-16; the version vendored in `C:/src/yolo-ui`); Bun 1.4.4.

## 1. Client runtime: krausest js-framework-benchmark, Chrome 156

Source: https://krausest.github.io/js-framework-benchmark/2026/chrome156.html (run published
2026-10-25, 201 keyed implementations, non-keyed retired). Retrieved 2026-11-04. The results table is
rendered client-side, so the raw sample arrays embedded in `results-Ch_eDRpy.js` were parsed with Bun
and the median of each sample set taken (`quoted`, medians computed by us, not the site's weighted
geometric mean). Durations in ms, memory in MB, sizes in KB. Framework rows as named by the benchmark:
`leptos-v0.7.0-keyed`, `dioxus-v0.7.2-keyed`, `react-hooks-v19.2.0-keyed`,
`react-compiler-hooks-v19.0.0-keyed`, `vanillajs-keyed`. TanStack has no row (it is a router/data
layer, not a renderer); the React rows stand for the TanStack stack. Note that the Rust rows are 0.7
builds, not 0.8 Dioxus or 0.8/0.9 Leptos.

Reading: Leptos and Dioxus are equal on CPU (1.28x vanilla) and both beat React on every update
benchmark, massively on `swap rows`. Leptos is the smallest Rust bundle and lands first paint at React
level; Dioxus 0.7.2 carries 2.4x the compressed bytes and 2.3x the first-paint of Leptos. React with
the React Compiler gains nothing here.

## 6. Measured vs quoted vs missing, in one line

Measured: the `Bun.serve` baseline on this host only. Quoted: krausest Chrome 156 medians (Leptos
0.7.0, Dioxus 0.7.2, React 19.2), TanStack SSR throughput (TanStack blog, Platformatic, Pareto), Bun
1.4 bundler and memory numbers, Leptos islands sizes, Dioxus 0.6 TodoMVC size, Subsecond timing claim.
Missing: any Leptos or Dioxus SSR req/s, TanStack on Bun req/s, TechEmpower axum figure (page not
retrievable), cold build times, hydration times, 0.8-era Rust bundle sizes. `bench/` is the plan to
turn every missing row into a measured one.
